# MuteluHub Design System (direction C2: ครามทอง ภาพนำ)

ตัวเลขทุกค่าอยู่ใน `tokens.css` / `tokens.json` เอกสารนี้อธิบายว่าใช้อย่างไร
ภาพอ้างอิง: `mockups/c2-home-and-fortune-tellers.png` (หน้าแรก + รายการหมอดู) และ `mockups/c-base-system.png` (ระบบพื้นฐาน: การ์ดสีเสื้อเต็ม, การ์ดหมอดู/สถานที่, chip)

## 1. แนวคิด
ผ้าครามกับดิ้นทอง ขลังและพรีเมียม แต่ไม่ใช่เว็บดูดวงพื้นดำม่วงนีออน
- พื้นเป็นน้ำเงินครามอุ่น `#172038` ไม่ใช่ดำ ไม่ใช่ม่วง
- ทองใช้เป็นเส้นบางและปุ่มหลัก ห้ามใช้ทองไล่สี (gradient) เป็นพื้นใหญ่
- ภาพเป็นตัวเล่าเรื่อง: หน้าแรก เทศกาล สถานที่ ใช้ภาพใหญ่ ข้อความวางทับภาพได้เมื่อมีม่านไล่สี
- ไม่มีแบนเนอร์ ไม่มี pop-up, affiliate อยู่ในเนื้อหาเสมอ

## 2. ฟอนต์
| บทบาท | ฟอนต์ | น้ำหนัก | ใช้กับ |
|---|---|---|---|
| Display | Trirong (มีหัว) | 500/600/700 | หัวข้อหน้า หัว section ชื่อหมอดู ชื่อสถานที่ ชื่อสี ตัวเลขมงคล |
| Body | Noto Sans Thai | 400/500/600 | ทุกอย่างที่เหลือ ปุ่ม chip ป้าย |

- ไฟล์ฟอนต์ self-host อยู่ใน `fonts/` (มาจาก @fontsource, OFL) ใช้ `fonts.css` ได้ทันที หรือติดตั้ง `@fontsource/trirong` + `@fontsource/noto-sans-thai` ในโปรเจกต์
- line-height เนื้อหา 1.6, หัวข้อ 1.45 ถึง 1.55 ห้ามต่ำกว่า 1.4 เพราะสระบนล่างไทยจะชนกัน (ทดสอบด้วยคำ: ปู่ ญี่ปุ่น ฤๅษี ฎีกา ผู้ใหญ่ น้ำมนต์)
- ขนาดตัวอักษรต่ำสุด 11px และใช้เฉพาะป้ายเครดิต/ป้าย affiliate

## 3. สี
ดู `tokens.css` ค่าคอนทราสต์ที่ตรวจแล้ว (WCAG AA ต้อง 4.5:1 ขึ้นไป):

| คู่สี | ค่า |
|---|---|
| text บน bg | 13.7:1 |
| text-muted บน surface | 6.7:1 |
| gold บน bg | 7.9:1 |
| ตัวอักษรครามบนปุ่มทอง | 7.9:1 |
| goal chip text ทุกสีบน surface | 8.2:1 ขึ้นไป |

`text-subtle #9C9686` ใช้เฉพาะ label เล็กที่ไม่สำคัญ (เช่น "ข้อมูลตัวอย่าง")

## 4. เป้าหมาย 8 อย่าง (แกนหลักของเว็บ)
ข้อมูลอยู่ใน `../data/goals.json` (slug ตรงกับ spec) ไอคอนอยู่ใน `icons/goals/<slug>.svg` (stroke = currentColor, viewBox 24)

แต่ละเป้าหมายมี 2 สี: `color` สำหรับไอคอน/ขอบ และ `text` สำหรับตัวอักษรใน chip
ใช้ซ้ำทุกที่: ปุ่มเลือกหน้าแรก, filter chip, tag บนการ์ด, หัว landing `/[goal]`

รูปแบบที่ใช้:
- **ปุ่มเลือกหน้าแรก** (grid 4x2): วงกลม 54px ขอบ `color` 40% พื้น `color` 8% ไอคอน 24px + label ใต้ (ชื่อสั้น)
  - selected: วงกลมทึบ `goldBright` ไอคอนสีคราม, วงแหวนทองห่างออกมา 4px, label ทอง ตัวหนา, `aria-pressed="true"`
- **Chip / filter**: สูง 36px pill, ขอบ `color` 40%, ตัวอักษร `text`, ไอคอน 16 ถึง 18px
  - selected: พื้น `goldBright` ตัวอักษรคราม (ทุกเป้าหมายใช้ทองเหมือนกันตอน selected เพื่อให้เห็นชัดว่าเลือกอะไร)
- **Tag บนการ์ด**: pill เล็ก 12px ขอบ `color` 40% ไม่มีไอคอน
- **Tag ศาสตร์**: pill ทึบทอง ตัวอักษรคราม (แยกจาก tag เป้าหมายให้ชัด)

ค่าที่เลือกต้องจำไว้ (localStorage หรือ cookie) และใช้เป็นค่าเริ่มต้นของทุกหน้า

## 5. ภาพ (raster)
| ประเภท | แหล่ง | การแสดงผล |
|---|---|---|
| สถานที่ | **ภาพจริงเท่านั้น** (ถ่ายเอง, Wikimedia Commons ที่เช็ก license แล้ว, ขออนุญาต) ห้ามดึงจาก Google Maps | ป้ายเครดิตมุมล่าง: พื้น `creditBg` ตัวขาว 10 ถึง 11px "ภาพ: ชื่อ / license" |
| หมอดู | ภาพวาด default ตามศาสตร์ ศาสตร์ละ 2 ถึง 3 แบบ เลือกจาก hash ของ id | สไตล์เดียวกันทั้งชุด: ภาพวาดสีฝุ่น เส้นทองบนคราม วงแหวนบางและดาวเล็ก ห้ามใช้ภาพคนจริง |
| เทศกาล / ต่างประเทศ | ภาพจริงพร้อมเครดิต | การ์ดภาพใหญ่ ข้อความวางล่างบนม่าน `--scrim-photo-bottom` |
| สินค้า affiliate | รูปจากร้านค้า | สี่เหลี่ยมจัตุรัส มุม 14px |
| Hero หน้าแรก | ภาพบรรยากาศ แสงโคมยามค่ำ | สูงราว 470px บนมือถือ ม่าน `--scrim-hero` ให้หัวข้ออ่านออก |

ทุก `<img>` ต้องมี alt ภาษาไทยที่บอกว่าเป็นภาพอะไร

## 6. Components
ดูหน้าตาจริงในไฟล์ mockup HTML (เปิดในเบราว์เซอร์ได้เลย inline style ทั้งหมดอ่านค่าได้ตรง ๆ)

1. **Header**: โลโก้ placeholder (วงกลมทอง + พระจันทร์เสี้ยว) + wordmark Trirong 19px, ปุ่มเมนู 44x44 (บน hero ใช้พื้นครามโปร่ง 50%)
2. **Goal picker**: ข้อ 4
3. **การ์ดสีเสื้อวันนี้**
   - แบบย่อ (หน้าแรก C2): กรอบทอง 3px, วงกลมสีเสื้อ 64px + ไอคอนเสื้อ, ชื่อสี Trirong 22px, บรรทัด "เลี่ยง ..." และปุ่มแชร์วงกลมทอง 44px
   - แบบเต็ม (ดู c-base-system): เพิ่มแถวสีที่ควรเลี่ยงแยก, ปุ่ม "แชร์ลง LINE" (ทอง) + "บันทึกเป็นรูป" (ขอบ)
   - แบบแชร์: 1080x1350 และ 1080x1920 **ยังไม่ได้ออกแบบ**
4. **ทางลัดเลขมงคล**: การ์ด surfaceRaised, วงกลมขอบทองใส่เลขไทย Trirong, ลูกศรขวา
5. **การ์ดเทศกาล**: ภาพเต็มการ์ดสูง 200px, ป้ายวันที่ pill ทองมุมซ้ายบน, เครดิตมุมขวาบน, ชื่อ Trirong 24px บนม่าน
6. **การ์ดสถานที่ (carousel)**: กว้าง 220px ภาพ 150px มุม 16px, ชื่อ + จังหวัด · เป้าหมาย, เลื่อนแนวนอนโผล่การ์ดถัดไปให้เห็นว่าปัดได้
7. **การ์ดต่างประเทศ**: แนวนอน ภาพซ้าย 132px + ข้อความขวา
8. **การ์ดหมอดู (list)**: ภาพ default 104x104 มุม 14px ซ้าย, ชื่อ Trirong 17px, tag ศาสตร์ (ทอง) + tag เป้าหมาย, ช่องทาง · จังหวัด, ราคาเริ่มต้น
9. **Filter bar มือถือ**: chip เป้าหมายเลื่อนแนวนอนแถวบนสุด + ปุ่ม "ตัวกรอง N" เปิด bottom sheet (ศาสตร์ ช่องทาง จังหวัด ราคา) **bottom sheet ยังไม่ได้ออกแบบ**
10. **บล็อก affiliate**: หัวข้อ Trirong + ป้าย "ลิงก์ affiliate" (pill ขอบ เล็ก) มุมขวา, 3 ถึง 4 ชิ้น grid, ชื่อสินค้า + [ราคา] · Shopee
    - แบบแทรกในรายการ: กรอบเส้นประ ภาพเล็ก 56px + ข้อความ + ป้าย affiliate
11. **ป้ายเครดิตรูป**: absolute มุมล่าง พื้นดำ 65% ตัวขาว 10 ถึง 11px มุม 4px

## 7. มือถือก่อน
- ออกแบบที่กว้าง 390px, gutter 16px, ทุกจุดกดอย่างน้อย 44x44
- จอใหญ่: คอลัมน์เนื้อหากว้างสุดราว 1200px, grid เป้าหมายเป็น 8 ช่องแถวเดียว, carousel กลายเป็น grid
- **ยังไม่มี mockup เดสก์ท็อป** ให้ขยายจากระบบนี้อย่างสมเหตุสมผล

## 8. สิ่งที่ยังไม่ได้ออกแบบ (ตาม brief ข้อ 5)
landing เป้าหมาย, โปรไฟล์หมอดู, รายการสถานที่ + แผนที่, หน้าสถานที่, เครื่องคำนวณเลขมงคล, ปฏิทินมงคล, หน้าเทศกาล, หน้าประเทศ, การ์ดแชร์, bottom sheet, OG image template
ให้สร้างจาก components ข้างบนให้สอดคล้องกัน
