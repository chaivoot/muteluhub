# MuteluHub

เว็บ directory สายมู (muteluhub.com): เริ่มจาก "อยากเสริมเรื่องอะไร" แล้วพาไปสีเสื้อมงคล เลขมงคล หมอดู สถานที่เสริมดวง และเทศกาล

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # unit tests (vitest)
npm run build
```

ตั้งค่า env ตาม `.env.example` (ใส่ `AGODA_CID` ใน Vercel เท่านั้น)

เอกสาร: `CLAUDE.md` (คำสั่งและสถานะ), `docs/mutelu-spec.md` (spec หลัก), `docs/design-brief.md`, `design/design-system.md`
