# Mutelu - สายมู Directory: Project Spec

> สถานะ: ร่างแนวคิด (2026-10-11) สำหรับส่งต่อ Claude Code
> ชื่อ Mutelu เป็นชื่อโปรเจกต์ชั่วคราว ยังไม่ยืนยันชื่อแบรนด์/โดเมน

---

## 1. หลักการออกแบบ (ล็อกแล้ว)

1. **เป้าหมายเป็นแกนหลักของทั้งเว็บ** ผู้ใช้เริ่มจาก "อยากเสริมเรื่องอะไร" ไม่ใช่เริ่มจากศาสตร์หรือประเภทเนื้อหา ทุก entity ติด tag เป้าหมายได้หลายค่า
2. **รูป default ตามประเภท** หมอดูทุกคนใช้รูป default ตามศาสตร์ ไม่อัปเดตรูปรายคน ยกเว้นสถานที่เสริมดวงที่ใช้รูปจริง + เนื้อหาจริง
3. **หารายได้ตั้งแต่วันแรก แต่ไม่รบกวนผู้ใช้** affiliate วางเป็นคำแนะนำในเนื้อหา (สิ่งที่ควรเตรียม / ของเสริมวันนี้) ไม่มีแบนเนอร์ ไม่มี pop-up
4. **SEO เกาะกระแส/เทศกาล** หน้าเทศกาลแบบ URL ไม่ใส่ปี อัปเดตทุกปี

## 2. Taxonomy กลาง

### 2.1 เป้าหมาย (goals) - ไม่เกิน 8
| slug | ชื่อ |
|---|---|
| love | ความรัก / เสน่ห์ |
| career | การงาน / ตำแหน่ง |
| money | การเงิน / โชคลาภ |
| business | ค้าขาย / ธุรกิจ |
| health | สุขภาพ |
| study | การเรียน / สอบ |
| family | ครอบครัว / มีบุตร |
| protection | แคล้วคลาด / ปกป้อง |

### 2.2 ศาสตร์ (disciplines) - จัดกลุ่ม 2 ชั้น
- **โหราศาสตร์**: โหราศาสตร์ไทย, เลข 7 ตัว 9 ฐาน / ทักษา, โหราศาสตร์ตะวันตก, โหราศาสตร์ภารตะ (Vedic), ปาจื้อ / ดวงจีน, Human Design
- **ไพ่และการเสี่ยงทาย**: ไพ่ทาโรต์, ไพ่ยิปซี / Lenormand, ไพ่ออราเคิล, เซียมซี / ไอจิง / Runes
- **ดูจากร่างกาย**: ลายมือ, โหงวเฮ้ง
- **ตัวเลขและชื่อ**: เลขศาสตร์ / Numerology, เบอร์มงคล / ทะเบียนรถ, ตั้งชื่อ / เปลี่ยนชื่อมงคล
- **พื้นที่และฤกษ์**: ฮวงจุ้ย, หาฤกษ์
- **สัมผัสพิเศษ**: ร่างทรง, นั่งทางใน / ญาณ / สื่อวิญญาณ

แต่ละศาสตร์มีรูป default 2-3 แบบ

## 3. ส่วนต่าง ๆ ของเว็บ

### 3.1 หมอดู (directory)
- 1 หมอดูอยู่ได้หลายศาสตร์ และถนัดหลายเป้าหมาย
- Filter: เป้าหมาย (บนสุดเสมอ), ศาสตร์, ช่องทาง (หน้าร้าน / ออนไลน์ / LINE / โทร), จังหวัด, ช่วงราคา
- รูป: default ตามศาสตร์หลัก เลือกแบบคงที่จาก hash ของ id (ไม่สุ่มใหม่ทุกครั้ง)
- OG image สร้างอัตโนมัติ: รูป default + ชื่อหมอดู + ศาสตร์
- อนาคต: claim listing ให้หมอดูอัปรูป/ข้อมูลเอง

### 3.2 สถานที่เสริมดวงในไทย
- รูปจริง + เนื้อหาจริง (แหล่งรูป: ถ่ายเอง, Wikimedia Commons เช็ก license, ขออนุญาต; ห้ามดึงจาก Google Maps)
- Filter: เป้าหมาย, องค์เทพ/สิ่งศักดิ์สิทธิ์, จังหวัด
- ข้อมูล: เวลาเปิด, ของไหว้ที่ต้องเตรียม, วิธีขอพร, วิธีแก้บน, พิกัด
- บล็อก Shopee: ของไหว้ที่ต้องเตรียม
- บล็อก Agoda: ที่พักใกล้เคียง (ต่างจังหวัด)

### 3.3 สถานที่มูต่างประเทศ
- แยกตามประเทศ (ตัวอย่างที่คนไทยนิยม: อินเดีย ฮ่องกง ไต้หวัน ญี่ปุ่น เนปาล จีน - ยังไม่ได้เช็กข้อมูลล่าสุด)
- รูปแบบคู่มือทริป + Agoda (+ ตัวเลือก Klook สำหรับทัวร์/ตั๋ว ภายหลัง)

### 3.4 เครื่องมือ: เลขมงคลจากวันเกิด
- Input: วันเดือนปีเกิด (+ เป้าหมาย)
- Output: เลขมงคลตามเป้าหมาย
- **ต้องตัดสินใจ**: เลือกหลักคำนวณหลักเดียว (Numerology / ทักษา / อื่น ๆ) และแสดงในหน้าว่าใช้หลักอะไร
- บล็อก Shopee: ซิมเบอร์มงคล
- ต่อยอดภายหลัง: เช็กเบอร์, เช็กชื่อ, ทะเบียนรถ

### 3.5 ปฏิทินมงคล
- ฤกษ์ดีตามประเภทงาน (แต่งงาน ขึ้นบ้านใหม่ เปิดร้าน ออกรถ ฯลฯ) ผูกกับเป้าหมาย
- อ้างอิงปฏิทินไทย: วันจันทรคติ, วันธงชัย, อธิบดี, โลกาวินาศ
- **ยังไม่ได้ข้อสรุป**: คำนวณเองด้วยโค้ด หรือคีย์มือรายปี; ยังไม่รู้ว่ามี dataset/API ไทยที่เชื่อถือได้หรือไม่
- บล็อก Shopee: ชุดขึ้นบ้านใหม่, ของใช้งานบวช/แต่ง

### 3.6 สีเสื้อมงคลวันนี้ (feature ดึงคนกลับรายวัน)
- แสดงบนหน้าแรก ตามเป้าหมายที่ผู้ใช้เลือก
- หลักทักษาที่จับคู่กับเป้าหมาย เช่น ศรี (เงิน/เสน่ห์), เดช (อำนาจ/การงาน), อายุ (สุขภาพ), มนตรี (ผู้ใหญ่อุปถัมภ์), บริวาร (คนรอบข้าง), กาลกิณี (สีที่ควรเลี่ยง)
- **ต้องตัดสินใจ**: ใช้ตารางคงที่ตามวันในสัปดาห์ หรือปรับรายปี; ถ้าอ้างอิงหมอดูดังต้องขออนุญาต/ให้เครดิต
- การ์ดรูปแชร์ได้รายวัน + push LINE OA ทุกเช้า (ภายหลัง)
- บล็อก Shopee: ของสีมงคลวันนี้ (เสื้อ กำไล กระเป๋าสตางค์)

### 3.7 หน้าเทศกาล / กระแส
- URL ไม่มีปี เช่น `/festival/kinje` อัปเดตเนื้อหาทุกปี (ใส่ปีใน title ได้)
- ปล่อย/อัปเดตก่อนเทศกาล 4-6 สัปดาห์
- หน้าเทศกาลคือจุดรวม: วันที่, สถานที่จัดงาน, Agoda, Shopee, คำแนะนำตามเป้าหมาย
- ตาราง events ในระบบ + แจ้งเตือนเจ้าของเว็บล่วงหน้าให้อัปเดต
- ปฏิทินกระแส (วันที่เช็กทุกปี): ปีใหม่ (ไหว้พระ 9 วัด, ดวง 12 ราศี), ตรุษจีน (ปีชง/แก้ชง), สงกรานต์, สารทจีน, คเณศจตุรถี, ไหว้พระจันทร์, กินเจ, ลอยกระทง, ดาวย้าย (ราหู/เสาร์ - ไม่มีวันตายตัว)
- อ้างอิง: กินเจ 2569 = 10-18 ต.ค. 2569 (ล้างท้อง 9 ต.ค.)

## 4. Affiliate

### 4.1 Shopee
- สินค้า curated ติด tag: เป้าหมาย, สี, ประเภทงาน (ฤกษ์), ผูกสถานที่ได้ (ของไหว้เฉพาะองค์)
- คุณค่าหลักคือ cookie ที่พาคนเข้า Shopee (ผู้ใช้ระบุ 7 วัน - ควรเช็กเงื่อนไขล่าสุดใน Shopee Affiliate)
- สีเสื้อรายวัน + ลิงก์สินค้า = ต่ออายุ cookie ต่อเนื่อง
- กติกาแสดงผล: อยู่ในเนื้อหา, 3-4 ชิ้นต่อบล็อก, มีป้ายบอกว่าเป็นลิงก์ affiliate
- Maintenance: ระบบเช็กลิงก์เสียเป็นระยะ + ลิงก์สำรอง (หมวด/ร้าน); ยังไม่รู้ว่า Shopee มี feed/API ให้ใช้แค่ไหน

### 4.2 Agoda
- ปัจจุบัน: ระบบใส่ลิงก์ต่อสถานที่ และเก็บ CID ไว้ใน env var บน Vercel
- ข้อเสนอ: ฟังก์ชันประกอบลิงก์อัตโนมัติจาก เมือง/จังหวัด/พิกัด ของสถานที่ + CID จาก env ใช้ร่วมกันทั้งหน้าสถานที่ หน้าจังหวัด หน้าเทศกาล
- **ยังไม่รู้**: รูปแบบ deep link ที่ Agoda partner รองรับ (city id, พิกัด, วันที่) ต้องดูจากบัญชี partner

## 5. Data model (ร่าง)

```
goals            (id, slug, name, icon, color)
discipline_groups(id, slug, name)
disciplines      (id, group_id, slug, name, default_images[])

fortune_tellers  (id, slug, name, bio, province, channels[], price_range,
                  contact{line, phone, fb, ig, web}, claimed bool)
  ↔ disciplines  (many-to-many, flag primary)
  ↔ goals        (many-to-many)

deities          (id, slug, name)            -- องค์เทพ/สิ่งศักดิ์สิทธิ์
places           (id, slug, name, type{temple, shrine, devalai, ...},
                  country, province, city, lat, lng,
                  opening_hours, offerings_text, how_to_pray, how_to_repay_vow,
                  images[], image_credits[], agoda_link_override)
  ↔ goals, ↔ deities

products         (id, title, shopee_url, fallback_url, image, price_hint,
                  colors[], last_checked_at, status)
  ↔ goals, ↔ event_types, ↔ places

event_types      (id, slug, name)            -- แต่งงาน ขึ้นบ้านใหม่ เปิดร้าน ...
  ↔ goals
auspicious_days  (date, event_type_id, quality, note, source)

daily_colors     (weekday | date, goal_id, color_name, hex,
                  taksa_role, avoid bool, source)

festivals        (id, slug, name, content, seo_title, seo_desc)
festival_dates   (festival_id, year, start_date, end_date, prep_date, notes)
  ↔ places, ↔ products, ↔ goals
```

## 6. URL / SEO (ร่าง)
- `/` หน้าแรก: เลือกเป้าหมาย, สีเสื้อวันนี้, เลขมงคล, เทศกาลที่กำลังมา
- `/[goal]` landing ตามเป้าหมาย เช่น `/money`
- `/[goal]/places`, `/[goal]/fortune-tellers`, `/[goal]/items`
- `/fortune-tellers/[discipline]`, `/fortune-tellers/[slug]`
- `/places/[province]`, `/places/[slug]`, `/abroad/[country]`
- `/tools/lucky-number`
- `/calendar/[event-type]`
- `/color-today`
- `/festival/[slug]`
- (ตัดสินใจภายหลัง: slug ภาษาไทย หรืออังกฤษ)

## 7. ลำดับการทำ (แนะนำ)
1. สีเสื้อรายวัน + เลขมงคล (ง่าย, ดึงคนกลับทุกวัน)
2. สถานที่ในไทย (SEO ระยะยาว)
3. หมอดู (ต้องมี supply + ระบบลงทะเบียน)
4. ต่างประเทศ + ปฏิทินมงคล
5. หน้าเทศกาลทำแทรกตามจังหวะ
