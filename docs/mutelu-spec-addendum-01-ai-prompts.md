# Spec Addendum 01: AI Prompt ดูดวง

> เพิ่มเติมจาก mutelu-spec.md (2026-10-11) ไม่แก้ของเดิม เป็นส่วนใหม่
> ให้ทำต่อจากงานที่ทำอยู่ ไม่ต้องรื้อโครงเดิม

---

## 1. ภาพรวม
คนจำนวนมากดูดวงกับ ChatGPT / Claude / Gemini แล้ว เว็บจะมี:
1. **คลัง prompt** แยกตามเป้าหมาย x ศาสตร์ คัดลอกไปใช้ได้ทันที
2. **Prompt generator** กรอกข้อมูลเกิด + เลือกเป้าหมาย + ศาสตร์ แล้วได้ prompt ที่ใส่ข้อมูลครบ
3. **ปุ่มถาม AI ต่อ** ในเครื่องมือเดิม (เลขมงคล, สีเสื้อ) ส่งผลลัพธ์เข้า prompt ให้เลย

ใช้ taxonomy เป้าหมายและศาสตร์ตัวเดิม (spec ข้อ 2)

## 2. หลักสำคัญ
- **AI เป็นผู้ตีความ ไม่ใช่ผู้คำนวณ** AI ทั่วไปมักผูกดวงไม่แม่นเพราะต้องใช้ตำแหน่งดาวจริง prompt จึงต้องส่งข้อมูลที่คำนวณแล้ว (จากเครื่องมือของเว็บ หรือผังดวงที่ผู้ใช้มี) แล้วให้ AI ตีความ
- **ทุก prompt ต่อท้ายด้วย guard block** (ข้อ 5) เสมอ
- **ไม่ส่งข้อมูลเกิดของผู้ใช้ขึ้น server** ประกอบ prompt ฝั่ง client ทั้งหมด ไม่เก็บ ไม่ log
- เชื่อมกับ directory: ท้ายหน้าผลลัพธ์มีบล็อก อยากคุยลึกกับหมอดูจริง ลิงก์ไปหมอดูที่ตรงเป้าหมาย/ศาสตร์

## 3. ศาสตร์ที่รองรับ (เฟสแรก)
เลือกเฉพาะที่ AI ตีความได้ดีโดยไม่ต้องคำนวณเอง:
- ไพ่ทาโรต์ / ออราเคิล (ผู้ใช้จั่วไพ่เอง แล้วใส่ชื่อไพ่)
- เลขศาสตร์ / เลขมงคล (ใช้ผลจาก /tools/lucky-number)
- ตีความผังดวงที่มีอยู่แล้ว (ผู้ใช้วางข้อมูลผังดวงเอง)
- สีเสื้อ / ทักษา (ใช้ผลจาก /color-today)
- คำถามทั่วไปตามเป้าหมาย (ปรึกษา วางแผน ไม่ทำนายเจาะจง)

ยังไม่ทำ: prompt ที่ให้ AI ผูกดวงจากวันเวลาเกิดเอง

## 4. Data model เพิ่ม

```
prompt_templates (
  id, slug, title, description,
  discipline_id   nullable,          -- null = ทั่วไป
  template        text,              -- มี placeholder {{field}}
  required_fields jsonb,             -- [{key, label, type: date|time|text|select|cards, options?}]
  follow_ups      text[],            -- prompt ถามต่อ
  is_featured     bool,
  sort_order      int
)
  ↔ goals (many-to-many)
```

- Placeholder ใช้รูปแบบ `{{key}}` เช่น `{{birth_date}}`, `{{goal}}`, `{{cards}}`, `{{lucky_numbers}}`, `{{question}}`
- Guard block เก็บเป็นค่าคงที่ตัวเดียวในโค้ด ต่อท้ายตอน render ทุกครั้ง ไม่ต้องใส่ซ้ำในแต่ละ template

## 5. Guard block (ต่อท้ายทุก prompt)

```
ข้อกำหนดในการตอบ:
- ใช้เฉพาะข้อมูลที่ฉันให้ ถ้าต้องใช้ข้อมูลที่ไม่มี เช่น ตำแหน่งดาวที่ไม่ได้ให้มา ให้บอกตรง ๆ ว่าไม่มีข้อมูล ห้ามเดา
- แยกให้ชัดว่าส่วนไหนคือหลักของศาสตร์ ส่วนไหนคือการตีความ
- ไม่ทำนายเรื่องโรคหรือการรักษา ถ้าเกี่ยวกับสุขภาพให้แนะนำปรึกษาแพทย์
- ไม่แนะนำการลงทุน หุ้น หรือการพนันแบบเจาะจง
- ตอบเป็นภาษาไทย อ่านง่าย ปิดท้ายด้วยสิ่งที่ลงมือทำได้จริง 2-3 ข้อ
```

## 6. ตัวอย่าง templates (seed data)

**tarot-love** (ไพ่ทาโรต์ x ความรัก)
```
ช่วยตีความไพ่ทาโรต์เรื่องความรักให้หน่อย
คำถามของฉัน: {{question}}
ไพ่ที่จั่วได้ (เรียงตามตำแหน่ง อดีต / ปัจจุบัน / อนาคต): {{cards}}
สถานะตอนนี้: {{relationship_status}}
อธิบายความหมายไพ่แต่ละใบในบริบทความรัก แล้วสรุปภาพรวม
```
follow_ups: ไพ่ใบไหนเป็นจุดที่ฉันควรระวังที่สุด / ถ้าอยากให้อนาคตดีขึ้น ควรทำอะไรใน 30 วันนี้

**lucky-number-money** (เลขมงคล x การเงิน)
```
ฉันเกิดวันที่ {{birth_date}}
เว็บคำนวณเลขมงคลให้ตามหลัก {{method}} ได้ผลดังนี้: {{lucky_numbers}}
ช่วยอธิบายว่าเลขเหล่านี้เกี่ยวกับการเงินของฉันอย่างไร และแนะนำวิธีใช้ในชีวิตประจำวัน เช่น เบอร์โทร เลขบัญชี ป้ายทะเบียน
```

**color-today-career** (สีเสื้อ x การงาน)
```
วันนี้วัน{{weekday}} สีมงคลด้านการงานของฉันคือ {{color}} และสีที่ควรเลี่ยงคือ {{avoid_color}}
วันนี้ฉันมีเรื่องงานคือ: {{question}}
ช่วยแนะนำการแต่งตัวและการวางตัวสำหรับวันนี้ให้เหมาะกับเรื่องนี้
```

**chart-reading-general** (ตีความผังดวงที่มีอยู่)
```
นี่คือข้อมูลผังดวงของฉันตามหลัก {{discipline}}:
{{chart_data}}
เรื่องที่อยากรู้: {{goal}} - {{question}}
ช่วยตีความจากข้อมูลนี้เท่านั้น
```

**general-plan** (ทั่วไป x ทุกเป้าหมาย)
```
ฉันอยากเสริมดวงเรื่อง{{goal}} สถานการณ์ตอนนี้คือ: {{question}}
ช่วยแนะนำในมุมความเชื่อแบบไทย เช่น การทำบุญ ไหว้พระ สีมงคล ควบคู่กับสิ่งที่ลงมือทำได้จริงในชีวิต
```

(เนื้อหา template ทั้งหมดเป็นฉบับร่าง เจ้าของจะปรับภาษาเองภายหลัง)

## 7. หน้า / URL เพิ่ม
- `/ai-prompts` คลัง prompt filter ตามเป้าหมาย + ศาสตร์
- `/ai-prompts/[goal]` landing ตามเป้าหมาย เช่น `/ai-prompts/love` (หน้า SEO หลัก)
- `/ai-prompts/p/[slug]` หน้า prompt เดี่ยว: คำอธิบาย, ฟอร์มกรอก field, preview prompt, ปุ่มคัดลอก, follow-ups, บล็อกหมอดูที่เกี่ยวข้อง
- `/tools/prompt-generator` เลือกเป้าหมาย > ศาสตร์ > กรอกข้อมูล > ได้ prompt

## 8. เชื่อมกับของเดิม
- `/tools/lucky-number` หลังแสดงผล: ปุ่ม ถาม AI ต่อ เปิด `/ai-prompts/p/lucky-number-[goal]` พร้อมเติมค่าให้ (ส่งผ่าน query string หรือ state ฝั่ง client เท่านั้น)
- `/color-today` เหมือนกัน ไป `color-today-[goal]`
- Landing เป้าหมาย `/[goal]` เพิ่ม section prompt แนะนำ 2-3 อัน

## 9. ปุ่มเปิดใน AI (ทางเลือก ต้องตรวจสอบก่อนทำ)
- ปุ่มหลักคือ **คัดลอก prompt** (ใช้ได้กับทุก AI แน่นอน)
- ปุ่ม เปิดใน ChatGPT / Claude ผ่าน URL ที่แนบ prompt ไปด้วย: **ยังไม่ยืนยันว่าแต่ละเจ้ารองรับ parameter แบบไหนและยังใช้งานได้อยู่** ให้ทดสอบจริงก่อน ถ้าไม่ชัวร์ไม่ต้องทำ
- ระวังความยาว URL ถ้า prompt ยาว

## 10. Analytics (ไม่เก็บข้อมูลส่วนตัว)
- นับ event: copy_prompt (slug, goal), open_followup, click_to_fortune_teller
- ห้ามส่งค่าที่ผู้ใช้กรอก (วันเกิด คำถาม ไพ่) เข้า analytics
