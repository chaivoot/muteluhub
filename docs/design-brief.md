# Design Brief: Mutelu - เว็บ directory สายมู

> ส่งให้ Claude Design ใช้ออกแบบหน้าจอ
> Mutelu เป็นชื่อโปรเจกต์ชั่วคราว ยังไม่ใช่ชื่อแบรนด์จริง

## 1. เว็บนี้คืออะไร
เว็บรวมทุกอย่างของสายมูในที่เดียว: หมอดูแยกตามศาสตร์, สถานที่เสริมดวงทั่วไทยและต่างประเทศ, เครื่องคำนวณเลขมงคลจากวันเกิด, ปฏิทินฤกษ์มงคล, สีเสื้อมงคลประจำวัน และหน้าเทศกาลตามกระแส (กินเจ ตรุษจีน ฯลฯ)

**หัวใจของ UX: ผู้ใช้เริ่มจาก "อยากเสริมเรื่องอะไร"** ทุกหน้าตอบเป้าหมายเดียวกัน

8 เป้าหมาย: ความรัก, การงาน, การเงิน/โชคลาภ, ค้าขาย, สุขภาพ, การเรียน/สอบ, ครอบครัว/มีบุตร, แคล้วคลาด/ปกป้อง
แต่ละเป้าหมายควรมีไอคอนและสีประจำของตัวเอง ใช้ซ้ำทั่วทั้งเว็บ (chip, filter, tag, หัวหน้า landing)

## 2. ผู้ใช้
- คนไทยทั่วไปที่สนใจดูดวง ไหว้พระ เสริมดวง ทุกช่วงอายุ
- ส่วนใหญ่น่าจะเข้าจากมือถือ ผ่าน Google และลิงก์ที่แชร์ในโซเชียล/LINE (สมมติฐาน ยังไม่มีข้อมูลจริง)
- **ออกแบบ mobile-first**

## 3. ความรู้สึกของแบรนด์
- น่าเชื่อถือ สะอาด อ่านง่าย ไม่ดูเป็นเว็บดูดวงราคาถูก
- มีความขลังและอบอุ่นแบบไทย-จีน แต่ไม่รก ไม่ฉูดฉาด
- เป็นมิตร ใช้งานทุกวันได้โดยไม่เหนื่อยตา
- เลี่ยง: พื้นดำม่วงนีออนแบบเว็บดูดวงทั่วไป, ภาพเทพ/พระที่ใช้ไม่ถูกบริบท, แบนเนอร์โฆษณา
- ขอ 2-3 แนวทางภาพรวมให้เลือกก่อนลงรายละเอียด

## 4. ข้อจำกัดสำคัญ
- **ภาษาไทยเป็นหลัก** เลือกฟอนต์ไทยที่อ่านง่ายบนมือถือ ระยะบรรทัดเผื่อสระบน-ล่าง
- **หมอดูไม่มีรูปจริง** ใช้ภาพ default ตามศาสตร์ (เช่น ลายมือ ไพ่ทาโรต์ ไพ่ออราเคิล โหงวเฮ้ง ฮวงจุ้ย ราว 20 ศาสตร์ ศาสตร์ละ 2-3 แบบ) ต้องดูตั้งใจ เป็นชุดเดียวกัน ไม่ดูเหมือนขาดรูป แนะนำเป็น illustration สไตล์เดียวทั้งชุด
- **สถานที่เสริมดวงใช้รูปจริง** ต้องมีที่วางเครดิตรูป
- **Affiliate ต้องไม่รบกวน** สินค้า Shopee และที่พัก Agoda อยู่ในเนื้อหาในรูปแบบคำแนะนำ เช่น บล็อก "สิ่งที่ควรเตรียม" หรือ "ของเสริมวันนี้" 3-4 ชิ้นต่อบล็อก มีป้ายเล็กบอกว่าเป็นลิงก์ affiliate ห้ามดูเป็นแบนเนอร์

## 5. หน้าจอที่ต้องการ (เรียงตามความสำคัญ)

**1. หน้าแรก**
- คำถามหลัก: วันนี้อยากเสริมเรื่องอะไร + ปุ่ม 8 เป้าหมาย (จำค่าที่เลือกไว้)
- การ์ดสีเสื้อมงคลวันนี้ ตามเป้าหมายที่เลือก (มีสีที่ควรเลี่ยงด้วย) + ปุ่มแชร์
- ทางลัดเครื่องคำนวณเลขมงคล
- เทศกาลที่กำลังจะมา
- ทางเข้าหมอดู / สถานที่ไทย / ต่างประเทศ / ปฏิทินมงคล

**2. การ์ดสีเสื้อวันนี้ (แชร์ได้)** ขนาดสำหรับแชร์ LINE/โซเชียล (เช่น 1080x1350 และ 1080x1920) บอกวัน, สีตามแต่ละเป้าหมาย, สีที่ควรเลี่ยง

**3. Landing เป้าหมาย** (ตัวอย่าง: การเงิน)
- สีเสื้อ/เลขมงคลด้านการเงิน, สถานที่ขอโชคลาภ, หมอดูที่ถนัดเรื่องเงิน, ของเสริมการเงิน (Shopee), ฤกษ์ที่เกี่ยวข้อง

**4. รายการหมอดู + filter**
- Filter: เป้าหมาย (บนสุด), ศาสตร์, ช่องทาง (หน้าร้าน/ออนไลน์/LINE/โทร), จังหวัด, ราคา
- การ์ดหมอดู: ภาพ default ตามศาสตร์, ชื่อ, tag ศาสตร์, tag เป้าหมาย, ช่องทาง, จังหวัด

**5. หน้าโปรไฟล์หมอดู** ข้อมูล, ศาสตร์, เรื่องที่ถนัด, ช่องทางติดต่อ, ราคา, หมอดูที่คล้ายกัน

**6. รายการสถานที่ + filter** filter เป้าหมาย, องค์เทพ, จังหวัด; มุมมองรายการ + แผนที่

**7. หน้าสถานที่** รูปจริง + เครดิต, ขอพรเรื่องอะไร, เวลาเปิด, ของไหว้ที่ต้องเตรียม (+ Shopee), วิธีขอพร/แก้บน, แผนที่, ที่พักใกล้ ๆ (Agoda)

**8. เครื่องคำนวณเลขมงคล** กรอกวันเกิด + เลือกเป้าหมาย, ผลลัพธ์อ่านง่ายและแชร์ได้, บรรทัดบอกว่าใช้หลักคำนวณอะไร, บล็อกซิมเบอร์มงคล

**9. ปฏิทินมงคล** เลือกประเภทงาน (แต่งงาน ขึ้นบ้านใหม่ เปิดร้าน ออกรถ), มุมมองเดือน, ไฮไลต์วันดี

**10. หน้าเทศกาล** (ตัวอย่าง: กินเจ) วันที่, ข้อควรรู้, สถานที่จัดงาน, ที่พัก, ของที่ต้องเตรียม

**11. หน้าประเทศ (มูต่างประเทศ)** สไตล์คู่มือทริป: สถานที่, เป้าหมาย, ที่พัก

## 6. Components ที่ใช้ซ้ำ
- Goal chip / goal filter (ไอคอน + สีประจำเป้าหมาย)
- การ์ดหมอดู, การ์ดสถานที่, การ์ดสินค้า affiliate, การ์ดที่พัก
- บล็อก affiliate ("สิ่งที่ควรเตรียม", "ของเสริมวันนี้", "ที่พักใกล้ ๆ") พร้อมป้าย affiliate
- การ์ดสีเสื้อ (ขนาดเล็กในหน้า + ขนาดแชร์)
- Filter bar แบบมือถือ (bottom sheet)
- ป้ายเครดิตรูป
- Template OG image: ภาพ default + ชื่อหมอดู + ศาสตร์

## 7. สิ่งที่ยังไม่มี
- ชื่อแบรนด์ / โลโก้ (ใช้ placeholder ได้)
- เนื้อหาจริง ใช้ข้อมูลตัวอย่างสมมติได้ แต่ห้ามใช้ชื่อหมอดูหรือแบรนด์จริง
